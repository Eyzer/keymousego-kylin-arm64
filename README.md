# KeymouseGo（银河麒麟 arm64 版）

基于 [taojy123/KeymouseGo](https://github.com/taojy123/KeymouseGo) v5.2.1 二次开发，
针对**银河麒麟 arm64** 重新构建打包，并做了界面全中文化与署名定制。

操作方式不变：按热键开始录制，你正常操作一遍，它把鼠标键盘动作全部记下来；
以后按热键回放，电脑就自动重复你刚才那套操作。

---

## 直接下载安装

安装包在 [`out/keymousego_5.2.1-1_arm64.deb`](out/keymousego_5.2.1-1_arm64.deb)。

拷到麒麟电脑上，在文件所在目录打开终端，执行：

    sudo dpkg -i keymousego_5.2.1-1_arm64.deb

装完在开始菜单搜「**KeymouseGo**」。

详细说明读 [`out/使用说明.md`](out/使用说明.md)。

## 本次定制内容

### 一、界面全中文，默认就是中文

上游自带的翻译只覆盖了界面骨架，程序运行中拼出来的状态文字
（就绪、执行中、执行次数、完成、中断等）全是写死的英文，中文界面下照样夹英文。
这些已全部抽出并补齐翻译，重新编译了语言包。

默认语言也改成一律简体中文，不再跟随系统区域设置。
语言选择会写入配置，下次启动保持上次选择。

> 顺带修了上游一个错误：保存语言选择时把两个方向相反的对照表用反了，
> 导致切换语言后下次启动总会变回中文。

### 二、界面底部作者信息

在主窗口原本空置的状态栏左侧常驻显示：

    作者：Eyzer　·　二次开发自：KeymouseGo v5.2.1

署名固定中文，不随语言切换变化。未改动顶部菜单栏结构。

## 目标系统要求

| 项 | 要求 |
| --- | --- |
| 架构 | arm64 / aarch64 |
| 系统 | 银河麒麟桌面操作系统 V10 **SP2 / SP3 及更新版本** |
| glibc | **≥ 2.31** |
| 图形环境 | X11 会话 |

> **重要**：界面框架 PySide6 6.5.3 的 arm64 预编译包要求 glibc ≥ 2.31。
> 麒麟 V10 SP2、SP3 及更新版本都是 2.31 基线，可以装；
> 更老的 **V10 SP1（Ubuntu 18.04 基线，glibc 2.27）装不上也跑不起来**。
>
> 必须是 X11 会话。用 `echo $XDG_SESSION_TYPE` 确认，显示 `x11` 即可。
> 若为 Wayland，录制功能不可用（系统底层限制）。

## 与官方版的差别（打包层面）

| | 官方 Linux 版 | 本仓库 |
| --- | --- | --- |
| 打包方式 | 源码 + 需自备 Python 环境 | 自带 Python 运行时的独立 deb 包 |
| 安装 | 手工装依赖 | 一条命令 |
| 数据存放 | 程序目录（装到系统目录会因只读而崩溃） | 用户目录，多用户互不干扰 |
| 界面语言 | 跟随系统区域设置 | 默认简体中文并可记忆 |
| 署名 | 无 | 界面底部常驻作者与来源信息 |

**程序设计目录问题**：上游把脚本、日志、配置直接存在程序所在目录，
装到只读的系统目录后普通用户一启动就因权限异常崩溃。
本版改为存放在用户目录下，未设置时行为与上游完全一致。

## 重新构建

需要一台 x86_64 Linux（Debian/Ubuntu）主机，联网且具备 root 权限，
约需 1 小时以上（依赖下载与模拟执行较慢）。

依次执行 `01_env.sh` → `02_pip.sh` → `03_build.sh` →
（chroot 内）`fill_deps2.sh` → `05_package.sh`，
最后用 `04b_verify.sh` 做完整验证。
